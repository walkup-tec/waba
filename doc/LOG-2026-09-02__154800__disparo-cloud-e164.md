# LOG — Disparo Cloud com números no padrão Meta

## Contexto

A planilha do disparo Cloud pode trazer telefone em máscara, DDI `+`/`00`, zero de tronco, Excel numérico/científico ou sem o 9º dígito móvel. A Cloud API da Meta exige E.164 **sem** `+` no campo `to`.

## Comandos / ações

- Normalizador `normalizeMetaSpreadsheetRecipient` (DDI 55, 9º dígito, máscara, Excel).
- Wizard Disparo Cloud na aba Templates: Portfólio → template aprovado → número Ativo → planilha → prévia → Iniciar.
- Envio por `sendTemplate` (não `sendText`). Alias `/s/:slug` por campanha; clique incrementa o disparo.

## Como validar

```bash
npm run test:meta-broadcast
```

No Laboratório: subir planilha com `(51) 99988-7766` e conferir na prévia `5551999887766`. Redeploy EasyPanel do `waba_disparador` para valer em produção.
