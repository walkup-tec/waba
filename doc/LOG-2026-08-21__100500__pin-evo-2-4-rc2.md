# Pin Evolution 2.4.0-rc2 (autorizado)

## Contexto

Usuário autorizou pin da imagem `evoapicloud/evolution-api:2.4.0-rc2` e um envio real para confirmar o botão.

## Impacto

- Serviço: `walkup_evo-walkup-api` (Evolution walkup)
- Instâncias WhatsApp reconectam ~1–3 min
- Rollback: script restaura a imagem anterior se GET `/` não for 2.4 ou vier `LICENSE_REQUIRED`

## Ações

- Script `scripts/pin-evo-2-4-rc2-vps.sh`
- Workflow `Pin Evolution 2.4.0-rc2 (SSH)` (secret `VPS_SSH_PRIVATE_KEY`)
- Um único `sendButtons` após GET `/` confirmar 2.4.x

## Palavras-chave

Evolution 2.4.0-rc2, pin imagem, EasyPanel, sendButtons, walkup_evo-walkup-api
