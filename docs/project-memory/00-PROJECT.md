# Projeto

WABA (Drax) — disparos e WhatsApp Business via Evolution API e Meta Cloud API.

Stack principal: TypeScript/Node, `index.html` do painel, Docker/EasyPanel, Traefik, Supabase.

Laboratório Meta Cloud: menus Conexão, Templates, Atendimento, Disparo Cloud e Automação. Templates cria e lista modelos; Disparo Cloud dispara template aprovado.
